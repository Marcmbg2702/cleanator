# Cleanator

Outil de nettoyage et d'optimisation pour Windows.

Téléchargez la dernière version dans l'onglet Releases.

## Identité visuelle

Logo « Bouclier Sain » : un bouclier validé, pour « PC protégé, PC propre ».

| Fichier | Usage |
| --- | --- |
| `assets/logo/cleanator-icon.svg` | Icône seule, fond transparent |
| `assets/logo/cleanator-icon-tile.svg` | Icône sur tuile sombre (application, raccourci) |
| `assets/logo/cleanator-logo-light.svg` | Logo complet sur fond clair |
| `assets/logo/cleanator-logo-dark.svg` | Logo complet sur fond sombre |
| `assets/logo/cleanator.ico` | Icône Windows (lecteur USB, raccourcis), 16 à 256 px |
| `assets/logo/*.png` | Versions PNG des logos, prêtes à l'emploi |
| `assets/banner.txt` | Bannière ASCII pour la console |
| `scripts/Show-CleanatorBanner.ps1` | Affiche la bannière en couleur au lancement d'un script |

Palette : Émeraude `#059669`, Menthe `#34D399`, Forêt `#052E2B`, Brume `#ECFDF5`.
